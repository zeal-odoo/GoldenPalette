# Golden 调色 / Golden Palette 1.0.19

**构建 / Build: 20** · **Universal: Apple silicon + Intel** · **macOS 12.7+**

## 简体中文

### 更新内容

- **从本色追加阴影与高光**：先调好 200 滴本色，分别取 20 滴放入两个调色杯，再按表追加指定颜色与滴数。本色剩余 160 滴；每份及整组耗料按实际追加量计算，分出的本色不会重复计量。
- **自然且更明显的明暗层次**：AI 优先使用 1～3 种追加颜料、总计 1～8 滴，必要时每份最多追加 20 滴。要求保留本色色相，控制饱和度与冷暖；预览明度最低差距提高到 18 L*，接近黑白边界时按剩余空间处理。
- **配方可独立保存与追溯**：阴影、高光保存完整本色快照，单独查看、复制或删除原本色卡片后仍可查到来源。旧版独立 200 滴配方保持原用量，重新生成才采用新方式。
- **田宫色库补全**：六类漆共 450 个可选有色参考，包含丙烯及珐琅 XF-85 橡胶黑，扩充 LP，并加入 AS、PS；支持色号和中英文名称搜索，附官方目录与色样来源记录。
- **GOLDEN Fluid 原料补充**：新增群青蓝 2400、永久浅绿 2250，Fluid 原料可选 15 色；SoFlat 12 色独立保留，旧套装配方继续兼容。
- **说明书与涂装考证**：支持按模型信息查找说明书、导入 PDF、联网考证配色、标注零件颜色，以及保存和导出标注 PDF。展示来源和不确定事项，支持手动核对与修正。
- **启动检查与维护**：启动时检查 Codex CLI 和当前模型，可修改 AI 设置或重试；补充中文代码注释及相关自动化测试。

本次发布包含上一次 GitHub 发布 1.0.13 之后的更新。应用界面目前主要为简体中文；GitHub 提供[中文](https://github.com/zeal-odoo/GoldenPalette/blob/v1.0.19/README.md)与[英文](https://github.com/zeal-odoo/GoldenPalette/blob/v1.0.19/README.en.md)使用说明。

### 下载与安装

1. 下载下方 Assets 中的 `GoldenPalette-1.0.19-universal.dmg`，支持 Apple 芯片和 Intel Mac，需要 macOS 12.7 或更新版本。
2. 退出正在运行的 Golden 调色，打开 DMG，将 `Golden调色.app` 拖入 `Applications`；更新时替换旧应用。
3. 退出磁盘映像，从“应用程序”打开。替换应用本体会保留已有项目、配方、说明书资料和 AI 设置。
4. AI 功能需要本机已经安装并登录 Codex CLI。在“系统设置 → AI 配置”选择账号可用的模型，必要时设置 CLI 路径。安装包不含 Codex CLI 或登录凭据；启动检查会向配置的模型发送一次简短请求。

当前应用使用 **Apple Development** 证书签名，**未使用 Developer ID 签名，也未经过 Apple 公证**。其他 Mac 可能显示安全验证提示或阻止打开。

### 校验与验证

将 DMG 和 `.sha256` 文件下载到同一目录，在该目录执行：

```sh
shasum -a 256 -c GoldenPalette-1.0.19-universal.sha256
```

应用版本已通过 88 项单元测试方法及 4 项界面流程测试；AI 服务集成使用固定响应验证协议和流程。DMG 已核验完整性、版本与构建号、两种架构和代码签名，验证记录随附件提供。

AI 考证、零件标注和配方仍需人工核对。RGB 与 L* 是屏幕参考，不能保证实物颜料成色或复现金属、珠光、荧光、透明等效果；请使用等体积滴量少量试调，并在干燥后对色。

## English

### What's new

- **Make shadows and highlights from the base mixture:** prepare a 200-drop base, take two separate 20-drop portions, and add the specified paints to each. The original base has 160 drops remaining. Variant and total quantities include actual additions without counting the portions twice.
- **Natural color with stronger contrast:** the AI is instructed to favor 1–3 added paints totaling 1–8 drops, with up to 20 added drops per variant when needed. Guidance preserves hue and controls saturation and warm/cool shifts. The minimum preview lightness difference is now 18 L*, adjusted for the remaining range near black or white.
- **Self-contained saved variants:** each shadow and highlight retains the complete original base recipe for independent viewing and copying, even after the base card is deleted. Legacy independent 200-drop recipes retain their original quantities; regenerating uses the new workflow.
- **Expanded Tamiya catalog:** 450 selectable colored references across six paint series, including XF-85 Rubber Black in acrylic and enamel, expanded LP coverage, and new AS/PS series. Search by code or Chinese/English name. Catalog coverage and swatch sources are documented.
- **More GOLDEN Fluid ingredients:** Ultramarine Blue 2400 and Permanent Green Light 2250 expand Fluid to 15 colors. SoFlat remains a separate 12-color set, and older saved sets remain readable.
- **Instruction manuals and painting research:** find manuals from kit details, import PDFs, research paint schemes with online sources, annotate part colors, and save or export annotated PDFs. Review sources, uncertainties, and editable part markers.
- **Startup checks and maintenance:** check Codex CLI and the selected model at startup, update AI settings or retry, and benefit from expanded code comments and automated coverage.

This release includes updates since the previous GitHub release, 1.0.13. The application interface is currently primarily in Simplified Chinese. [Chinese documentation](https://github.com/zeal-odoo/GoldenPalette/blob/v1.0.19/README.md) and [English documentation](https://github.com/zeal-odoo/GoldenPalette/blob/v1.0.19/README.en.md) are available on GitHub.

### Download and install

1. Download `GoldenPalette-1.0.19-universal.dmg` from Assets below. It supports Apple silicon and Intel Macs running macOS 12.7 or later.
2. Quit Golden Palette, open the DMG, and drag `Golden调色.app` into `Applications`. Replace the previous app when updating.
3. Eject the disk image and open the app from Applications. Replacing the application preserves projects, recipes, manual studies, and AI settings.
4. AI features require Codex CLI to be installed and signed in on this Mac. Open `系统设置 → AI 配置` (Settings → AI Configuration), select a model available to your account, and set the CLI path if necessary. The installer includes neither Codex CLI nor credentials. Startup checks send a short request to the configured model.

The application is signed with an **Apple Development** certificate. It is **not Developer ID signed or notarized by Apple**; macOS on another machine may show a verification warning or prevent it from opening.

### Checksum and validation

Download the DMG and `.sha256` file into the same folder, then run:

```sh
shasum -a 256 -c GoldenPalette-1.0.19-universal.sha256
```

The application version was validated with 88 unit test methods and four UI workflow tests. AI integration tests use fixed responses to check the protocol and workflow. DMG integrity, bundle version/build, both architectures, and the code signature were verified; a verification record is included with the assets.

Research findings, part annotations, and recipes require human review. RGB and L* are screen references and cannot guarantee physical paint matches or reproduce metallic, pearlescent, fluorescent, or transparent effects. Test small mixtures using equal-volume drops and compare them after drying.
