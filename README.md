# Golden 调色

用于记录项目颜色和生成模型、美术颜料调色配方的 macOS 应用。

- 输入 RGB 或选择颜色，通过本机 Codex CLI 生成本色、阴影色、高光色配方。
- 在“AI 调色 → 调色原料”中选择 GOLDEN SoFlat 12 色或 Fluid Acrylics 13 色。两套原料分别使用，AI 只使用所选套装。每份配方独立按 200 滴计算，列出颜料系列、色号、用量和调色步骤。
- 可以把田宫或郡士的具体色号作为参考标准，由 AI 用这些 GOLDEN 原料配出接近该标准的本色、阴影色、高光色。
- 支持多个 RGB、品牌标准色或两者混合按比例交给 AI 合成目标色，例如郡士 H1 30% + H2 70%；比例总和不足或超过 100% 时按相对权重处理。
- 按项目保存颜色和配方，支持单独删除颜色；查看配方和编辑颜色窗口采用毛玻璃背景。
- 在应用内的系统设置中配置模型、推理强度和 Codex CLI 路径。

## 安装和使用

系统要求为 macOS 12.7 或更新版本。发布的 Universal DMG 支持 Apple 芯片和 Intel Mac。

从 GitHub Releases 下载 DMG，将 `Golden调色.app` 拖入 `Applications`，退出磁盘映像后从“应用程序”打开。

AI 功能需要本机已安装并登录 Codex CLI。打开应用的“系统设置 → AI 配置”，填写当前账号可用的模型，必要时指定 CLI 路径。安装包不包含 Codex CLI 或登录凭据。

当前安装包使用 Apple Development 证书签名，尚未使用 Developer ID 签名或经过 Apple 公证；其他 Mac 可能显示安全验证提示或阻止打开。

AI 配方和屏幕色样仅供参考，实际颜料请先少量试调。

## 多色合成

在项目的“AI 调色 → 多色合成”中，每组均可选择“RGB”或“品牌标准色”。例如第一组选择“郡士 Mr.Hobby → 水性 Hobby Color · H → H1 白色”，占比填写 30%；第二组选择同漆系的 H2 黑色，占比填写 70%，然后生成配方。色号支持搜索，每组可独立选择品牌和漆系，也可与自定义 RGB 混合使用。

AI 会收到每组的品牌、漆系、色号、预览 RGB 和占比，再合成目标色。实际调色仍使用所选的 SoFlat 12 色或 Fluid 13 色，分别给出本色、阴影色、高光色各 200 滴的配方。输入比例不是最终 GOLDEN 原料的滴数比例。

保存的三色配方会保留全部输入色号、比例和 RGB 快照，查看与复制配方时可追溯原始组合。切换某组的漆系会清除该组色号，修改输入会清除尚未保存的结果；旧版纯 RGB 合成配方仍可读取。

## 品牌标准色

在项目内打开“AI 调色”，先选择调色原料套装，再在“品牌标准色”中选择参考品牌与漆系，搜索并点选具体色号。例如选择田宫 XF-53 或郡士 C13，AI 会把其品牌、色号和名称作为目标参考，实际配方仅使用所选的 SoFlat 12 色或 Fluid Acrylics 13 色。每份 200 滴分别调制，三份共 600 滴。

切换调色原料套装、参考品牌、漆系、色号或输入方式会清除尚未保存的生成结果；切换原料套装也会取消正在生成的请求。配方会保存所选套装和本色参考标准，再次打开同一项目的 AI 调色时恢复最近保存的选择。“单个颜色”和“多色合成”同样只使用所选套装，田宫或郡士的品牌色号仅作为目标参考。

| 品牌 | 漆系 | 收录数量 |
| --- | --- | --- |
| GOLDEN | 指定的 SoFlat 12 色 | 12 |
| GOLDEN | Fluid 10 色套装及 3 种补充色 | 13 |
| 田宫 | 丙烯 X / XF | 42 |
| 田宫 | 珐琅 X / XF | 42 |
| 田宫 | Lacquer LP | 32 |
| 田宫 | 喷罐漆 TS（有色参考） | 98 |
| 郡士 | Mr.Color C | 50 |
| 郡士 | 水性 Hobby Color H | 38 |
| 郡士 | Acrysion N | 40 |

除 TS 系列外，田宫与郡士目前收录常用实色，并非完整厂商目录；不包含金属漆、透明漆、稀释剂等。色号与名称参考[田宫官方色表](https://www.tamiya.com/cms/img/usr/inst/paints/202405_paints.pdf)及[郡士官方目录](https://www.mr-hobby.com/en/record-download/catalog/23)。屏幕色块为近似示意色，并非官方实测 RGB；AI 会结合品牌、色号、名称和预览生成 GOLDEN 试调配方，200 滴仅计算颜料，不含水或媒介。

在“品牌标准色 → 田宫 Tamiya → 喷罐漆 · TS”中可选择 TS 参考色，例如 TS-32、TS-50、TS-102，支持按色号及中英文名称搜索。色号和英文名称按 [田宫官方 TS 目录](https://www.tamiya.com/english/products/list.html?genre_item=e_504030)核对（2026-10-09），收录 TS-1～TS-102 中的 98 个有色款；TS-13、TS-65、TS-79、TS-80 为无色罩光款，不作为独立目标色收录。TS 的 RGB 是应用中的近似预览值，并非厂商发布的 RGB。金属、珠光、荧光和有色透明款仅作为近似颜色参考，不复现这些特殊效果；界面、AI 提示和保存的配方说明中均标明此限制。TS 不会加入原料套装，实际用漆仍是所选的 SoFlat 12 色或 Fluid 13 色。

Fluid 原料包括 [0928 官方 10 色调色套装](https://goldenartistcolors.com/products/fluid-acrylics-mixing-set)的 2009、2008、2210、2305、2260、2255、2270、2275、2040、2380，以及吡咯橙 2276、二噁嗪紫 2150、黄赭石 2407；色号与名称依据 [GOLDEN Fluid 官方色表](https://goldenartistcolors.com/products/golden-artist-acrylics/fluid/pigment-data)。SoFlat 与 Fluid 的同名色按系列和色号分别记录，不能直接等量替换；请使用等体积滴量，成色、光泽和遮盖力需通过干燥小样确认。

参考色的品牌与漆系会分别记录，即使田宫丙烯漆和珐琅漆使用相同色号也能区分。已有配方保留原始用漆记录与用量，包括旧的 SoFlat 12 色配方及 1.0.7 的 25 色组合配方。新生成的配方只能选择单套原料；从旧组合配方进入 AI 调色时默认选择 SoFlat 12 色，可自行切换为 Fluid 13 色。

## RGB 来源与核对

2026-10-09 按 [GOLDEN 官方调色器](https://goldenartistcolors.com/mixer/acrylic?tab=palette-builder)实际加载的[原始数据](https://assets.goldenartistcolors.com/mixerPaintData/index.json)逐色核对。Fluid 13 色均改用对应条目的 `paintColor.srgb`；AI 原料清单也包含这些数值。鼠标停留在原料行可查看 sRGB、HEX 和来源说明。

二噁嗪紫等深色在原色预览中可能接近黑色，以上数值照录官网数据。屏幕参考值相同不保证实物颜料成色相同；仍需少量试调，并以干燥小样对色。

官方调色器目前没有 SoFlat 专用色库，核对的 [SoFlat 官方产品数据](https://goldenartistcolors.com/products/golden-artist-acrylics/soflat/pigment-data)中也没有这 12 色的有效专用 RGB 字段。因此 SoFlat 保留原有近似色并明确标注，不套用其他系列同名颜料的数值。两套原料仍分别选择。

1.0.9 起，保存品牌参考色时同时保存其 RGB 快照，避免日后色库更新使旧配方失效。1.0.7–1.0.8 的 Fluid 参考色按旧预览值恢复，本色、阴影色、高光色的已存目标和用量保持原样；重新选择品牌标准色生成新配方时使用当前色库。

## 开发

使用 Xcode 打开 `Golden调色.xcodeproj`，在 Signing & Capabilities 中选择自己的开发团队，然后使用 `Golden调色` scheme 构建和运行。

`Golden调色 Release` 是共享的 Release scheme。生成通用安装包时，选择 `Any Mac (arm64, x86_64)` 构建目标。

单元测试位于 `Golden调色Tests`，界面测试位于 `Golden调色UITests`，可在 Xcode 中执行。AI 服务测试使用固定数据和模拟 CLI，不需要调用真实模型。

版本号由项目的 `MARKETING_VERSION` 和 `CURRENT_PROJECT_VERSION` 管理。每次应用迭代递增版本号和构建号；DMG 与校验文件存放在不纳入 Git 的 `dist/` 目录，通过 GitHub Releases 分发。
